Bullet Hell Game Tutorial using Felgo

Introduction

This tutorial describes how to create a simple 2D Bullet Hell Game using Felgo.

The tutorial will go in details on how to implement the player control and shooting mechanics, enemies and their attack patterns, wave spawning and scene management.

The source code for the finished is available on GitHub

Assets

The art assets used throughout this tutorial are from Kenney and are available here under CC0 1.0 License. This asset pack doesn't cover all of the need art assets, thus some of the missing ones were hand-drawn in the same style. All of the used art assets are available in GitHub Repository under assets/entities

The pixel font used in the game is available on Google Fonts

Project Setup

Start by creating a new Felgo Games project in Qt Creator. Sepcifically we will need New - Empty Felgo Project template.
